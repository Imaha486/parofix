parofix チュートリアル
パロディウス ポータブル (PSP) の差し替え BGM をサントラ CD の音源で復元する

このマニュアルは、PSP『パロディウス ポータブル』の UMD イメージ (ISO) に含まれる パロディウスだ! ステージ4 と 極上パロディウス ステージ1・ステージ3ボス の BGM を、 CD『ミュージック フロム コナミアーケードシューティング』の音源で差し替え、 PARODIUS-PORTABLE_converted.ISO を作るまでの手順を、環境構築から順に説明します。

用意するもの
・Windows 10/11 の PC
・自分で吸い出した『パロディウス ポータブル』の ISO（例: PARODIUS-PORTABLE.ISO）
・CD『ミュージック フロム コナミアーケードシューティング』DISC 3 と DISC 5
・parofix 一式 (parofix_vX.X.zip)

1. Python 3.8 以上のインストール

公式サイト python.org/downloads/windows から Windows 用インストーラ（64bit）をダウンロードします。parofix は Python 3.8 以上で動きます。 特にこだわりが無ければ最新の 3.x で構いません。

インストーラの最初の画面で 「Add python.exe to PATH」（古い版では「Add Python 3.x to PATH」）に 必ずチェックを入れてから「Install Now」を押します。

インストール後、スタートメニューから コマンド プロンプト（または PowerShell）を開き、 次のコマンドでバージョンが表示されれば成功です。

py --version
python --version
py は Windows 版 Python に付属するランチャーで、複数バージョンを入れていても py -3.8 のように版を選べます。このマニュアルでは以降 py を使います。 py が無い環境では python に読み替えてください。

2. 仮想環境 (venv) の作成

parofix が必要とする追加ライブラリは numpy だけです。 システムの Python を汚さないよう、作業フォルダに仮想環境を作ってそこに入れます。

作業フォルダを作ります。日本語や空白を含まないパスにすると後々トラブルが減ります。例として C:\parofix を使います。

mkdir C:\parofix
cd /d C:\parofix

仮想環境を作成して有効化します。

py -m venv venv
venv\Scripts\activate

有効化されるとプロンプトの先頭に (venv) と表示されます。 特定の版を使いたいときは py -3.8 -m venv venv のように指定します。

PowerShell で activate が「スクリプトの実行が無効」と拒否される場合は、 いったん Set-ExecutionPolicy -Scope CurrentUser RemoteSigned を実行するか、 コマンド プロンプト (cmd.exe) を使ってください。

numpy をインストールします。

python -m pip install --upgrade pip
python -m pip install numpy
次回以降、作業を再開するときは cd /d C:\parofix → venv\Scripts\activate の 2 行だけで OK です。

3. parofix の配置

parofix_vX.X.zip を展開し、中の parofix フォルダの中身を C:\parofix に置きます。 置き終わると次のようになります。

C:\parofix\ ├─ venv\ ← 手順 2 で作った仮想環境 ├─ parofix.py ← 起動スクリプト ├─ parofix\ ← 本体 ├─ bin\atracdenc.exe ← 同梱の ATRAC3 エンコーダ ├─ config\parodius_portable.json ├─ config\my_config_example.json ├─ docs\tutorial.html ← このファイル ├─ run.bat └─ README.md

ISO をここにコピーします（名前はそのままで構いません。以下 PARODIUS-PORTABLE.ISO とします）。

動作確認として、ISO の中身が一覧できるか試します。

python parofix.py bgm-list --iso PARODIUS-PORTABLE.ISO --target paro4

極上パロディウスの 46 曲が [ 11] ... 12SD_BGM1 のように並べば準備完了です。

4. CD から該当トラックを吸い出す

差し替えに使う CD トラックは次の 3 曲です。

ゲーム / 場面CDトラック曲名差し替え先
パロディウスだ! ステージ4（日本面）DISC 342嗚呼！日本旅情 (4st.BGM)paro2 #7
極上パロディウス ステージ1（クレーン面）DISC 535イン・ザ・クレーンゲーム (1st.BGM)paro4 #11 (12SD_BGM1)
極上パロディウス ステージ3 ボスDISC 542クッキングマンボ (3st.ボスBGM)paro4 #17 (18SD_BOSS3)

お好みのリッピングソフトで上の 3 トラックを WAV（44.1kHz / 16bit / ステレオ、CD そのまま）で取り込みます。 Exact Audio Copy、foobar2000、Windows Media Player、iTunes 等どれでも構いません。 音量の正規化（ノーマライズ）や ReplayGain の適用は OFF にしてください。

FLAC で取り込んでも使えますが、その場合は ffmpeg.exe を C:\parofix\bin\ に置く必要があります （gyan.dev などの Windows ビルドから ffmpeg.exe だけ取り出せば十分です）。 WAV なら ffmpeg は不要です。

5. ファイル名とフォルダ構成

C:\parofix\cd フォルダを作り、吸い出した WAV を次の名前にリネームして置きます。

CD トラックファイル名
DISC3 - 42 嗚呼！日本旅情paroda_st4_kennomai.wav
DISC5 - 35 イン・ザ・クレーンゲームgokupa_st1_in_the_mood.wav
DISC5 - 42 クッキングマンボgokupa_st3boss_mambo5.wav
C:\parofix\ ├─ PARODIUS-PORTABLE.ISO ├─ my_config.json ← 次の手順で作る └─ cd\ ├─ paroda_st4_kennomai.wav ├─ gokupa_st1_in_the_mood.wav └─ gokupa_st3boss_mambo5.wav

別の名前にしたい場合は、設定ファイルの "wav" を合わせて書き換えれば問題ありません。

6. 設定ファイルの確認

config\my_config_example.json を C:\parofix\my_config.json にコピーし、メモ帳などで開きます。 内容は次のとおりで、ループ位置には上記 3 トラックの CD 音源で検出・試聴確認済みの値が入っています。 拡張子だけ .flac → .wav に合わせてください。

{
  "iso": "PARODIUS-PORTABLE.ISO",
  "defaults": { "encoder": "atracdenc", "bitrate": 132, "gain_db": 0 },
  "replacements": [
    { "target": "paro2", "index": 7,  "wav": "cd/paroda_st4_kennomai.wav",
      "loop_start": 68470,  "loop_end": 1363995,
      "also_music_mode": true, "menu_index": 42 },

    { "target": "paro4", "index": 11, "wav": "cd/gokupa_st1_in_the_mood.wav",
      "loop_start": 441832, "loop_end": 2395297,
      "also_music_mode": true, "menu_index": 69 },

    { "target": "paro4", "index": 17, "wav": "cd/gokupa_st3boss_mambo5.wav",
      "loop_start": 239851, "loop_end": 1976752,
      "also_music_mode": true, "menu_index": 76 }
  ]
}
キー意味
iso元 ISO。設定ファイルからの相対パス
target / index差し替え先のゲームとトラック番号（上の表のとおり）
wavCD 音源ファイル
loop_start / loop_endループ区間（サンプル数）。loop_end 以降（2 周目・フェードアウト）は切り捨てられ、容量も小さくなります
also_music_mode / menu_indexミュージックモードの同じ曲も差し替える
gain_db音量補正。ゲーム内で CD 音源だけ大きい/小さいと感じたら ±2 程度で調整
ループ位置の値は、CD のプレス違いや取り込みソフトのオフセット補正によって数十サンプル前後ずれることがあります。 継ぎ目にわずかなノイズを感じる場合は次の手順 7 で検出し直してください。

7. （任意）ループ位置の検出・確認

自分の音源で検出し直すときは loopfind を使います。--near に「ループが始まるおおよその位置」を与えると、 その付近で継ぎ目が最も滑らかな点をサンプル単位で探します。

python parofix.py loopfind cd\gokupa_st1_in_the_mood.wav --near 0:10.0  --preview seam_itm.wav
python parofix.py loopfind cd\gokupa_st3boss_mambo5.wav  --near 0:05.7  --preview seam_mambo.wav
python parofix.py loopfind cd\paroda_st4_kennomai.wav    --near 0:01.25 --preview seam_kennomai.wav

結果の「config には "loop_start": ..., "loop_end": ... と書けます」の行をそのまま設定ファイルに転記します。 --preview で出る WAV は「loop_end 手前 4 秒 → ループで戻って 6 秒」を 2 回繰り返したもので、継ぎ目を試聴できます。 継ぎ目一致度は 0.8 以上なら自然に繋がります（基板録音はテンポが微妙に揺れるので 1.0 にはなりません）。

8. 変換の実行

仮想環境を有効にした状態で実行します。

cd /d C:\parofix
venv\Scripts\activate
python parofix.py run my_config.json

または my_config.json を run.bat にドラッグ＆ドロップしても同じです （run.bat は同じフォルダに venv があれば自動で有効化します）。

処理は 1〜2 分で終わり、次のように表示されれば成功です。

=== 出力 ISO の確認 ===
  パロディウスだ! 〜神話からお笑いへ〜: 34 トラック
    [7] ATRAC3 132kbps ch=2   30.93s ... loop 68470-1363995 (1.55s-30.93s)  OK
  ミュージックプレイヤーモード（全曲）: 232 トラック
    [42] ... OK   [69] ... OK   [76] ... OK
  極上パロディウス 〜過去の栄光を求めて〜: 46 トラック
    [11] ATRAC3 132kbps ch=2   54.32s ... loop 441832-2395297 (10.02s-54.32s)  OK
    [17] ATRAC3 132kbps ch=2   44.82s ... loop 239851-1976752 (5.44s-44.82s)  OK

完成: C:\parofix\PARODIUS-PORTABLE_converted.ISO
出来上がりは PARODIUS-PORTABLE_converted.ISO（約 357MB。ファイル領域を詰め直すので元より小さくなります）。 元の ISO は書き換えられません。PARODIUS-PORTABLE_work\ には生成した .at3 と bgm.bin が残ります（不要なら削除可）。

9. 動作確認

PPSSPP で PARODIUS-PORTABLE_converted.ISO を起動し、メインメニューで ◀▶ でゲームを切り替え、 極上パロディウスを選んでステージ1 の BGM を確認します。パロディウスだ! はステージ4（日本面）です。

ミュージックモードでも、該当する曲名のトラックが差し替わっていることを確認します。 形式チェックだけなら次のコマンドでも行えます（元から入っている長尺曲に対するサイズ警告は無視して構いません）。

python parofix.py verify --iso PARODIUS-PORTABLE_converted.ISO

実機 (CFW) で使う場合は ms0:/ISO/ にコピーしてください。通常の ISO9660 イメージなので特別な設定は不要です。

10. 困ったとき

症状対処
'python' は内部コマンド…として認識されていませんインストール時に PATH を追加していません。インストーラを再実行して「Modify」→「Add Python to environment variables」にチェック、または py を使う
ModuleNotFoundError: No module named 'numpy'仮想環境が有効になっていません。venv\Scripts\activate を実行してから再度
atracdenc が見つかりませんbin\atracdenc.exe が無いか、zip 展開時に階層がずれています。parofix.py と同じ場所に bin フォルダがあるか確認
44.1kHz の PCM WAV ではありませんFLAC/MP3 や 48kHz の音源です。WAV で取り込み直すか bin\ffmpeg.exe を置く
SmartScreen / ウイルス対策が atracdenc.exe を止めるオープンソースの atracdenc を静的ビルドしたものです（bin\licenses 参照）。除外設定するか、自分でビルドしたものに差し替えても動きます
差し替えた曲だけ鳴らないv1.1 以前の既知の問題（ヘッダの endSample 条件）です。v1.2 以降で変換し直してください。verify で該当トラックに NG が出ないことを確認
ループの継ぎ目にプチノイズ手順 7 で自分の音源から loopfind --near し直す。別の開始位置（例: 剣の舞 361546-1657120、マンボ 84767-1821857）も試せます
CD 音源の音量がゲーム内の他曲と違う該当行に "gain_db": -2 のように追加
